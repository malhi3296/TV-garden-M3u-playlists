## 🚀 How to Use

### Method 1: IPTV Apps (TiviMate, IPTV Smarters, OTT Navigator, etc.)
1. Open your IPTV application.
2. Navigate to **Add Playlist** / **M3U Playlist**.
3. Select **URL** input type.
4. Copy and paste one of the raw links listed above.
5. Save and refresh the playlist!

### Method 2: VLC Media Player (PC / Mac)
1. Open **VLC Media Player**.
2. Press `Ctrl + N` (Windows) or `Cmd + N` (Mac) to open **Network Stream**.
3. Paste the **TV** or **Radio** raw URL.
4. Click **Play**.
